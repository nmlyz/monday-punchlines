A tiny program that writes one joke about Monday mornings to a text file.
The joke is a single line: trying to ghost Monday, and Monday answering back
from the calendar, the inbox, and the boss's mouth.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (101 characters, UTF-8, no trailing newline).
